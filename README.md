## 🚀 Sobre mí

Soy **Desarrollador Full-Stack y Backend Junior** apasionado por construir soluciones robustas, escalables y seguras desde cero. Mi enfoque abarca la integración de APIs REST, arquitecturas de microservicios, productos de datos con IA y despliegues contenerizados con testing automatizado y flujos CI/CD.

Cuento con experiencia práctica en múltiples aplicaciones de alto impacto (incluyendo plataformas territoriales de datos, e-commerce con editor 3D y sistemas de microservicios). ## 🏗️ Proyectos Destacados

### [🏙️ Manrique EduDigital — Producto de Datos & Alerta Temprana](https://github.com/josuel-munendez/ManriqueEduDigital)
Plataforma de historial académico digital y alerta temprana de deserción escolar para la Comuna 3 - Manrique (Diplomado Territorio INN 2026).
* **Stack:** Python, Streamlit, DuckDB, Pandas, Pandera, Scikit-Learn (Random Forest), LangChain, ChromaDB.
* **Logros:**
  * Pipeline ETL multi-fuente con contratos de datos (`Pandera`) y almacenamiento en almacén analítico (`DuckDB`).
  * Modelo de Machine Learning supervisado para clasificación y alerta temprana de riesgo de deserción escolar.
  * Asistente conversacional RAG con grounding estricto y portal móvil con validación de certificados por código QR.

### [🚗 Movilidata OS — Plataforma Inteligente de Movilidad Urbana](https://github.com/josuel-munendez/Medellin-Propuesta-Digital-de-Trafico_SENA-Hackathon-2026)
Plataforma web de monitoreo vial y visualización geoespacial desarrollada para el HackData CTGI SENA 2026.
* **Stack:** Vue 3, Vite, Leaflet, Chart.js, Django REST Framework, scikit-learn, APIs externas (OpenWeatherMap, TomTom).
* **Logros:**
  * Visualización de tráfico en tiempo real, capas geoespaciales y mapas de calor (*heatmaps*).
  * Módulo de analítica predictiva y reportes ciudadanos con soporte PWA.

### [🎨 RED Estampación — E-commerce con Editor 3D (Proyecto Real ADSO)](https://github.com/eliassidez123234dfs/projecto_formativo)
Plataforma e-commerce para cliente real con renderizado de texturas e integración de pagos.
* **Stack:** Django, React.js, Three.js, Tailwind, PostgreSQL, MongoDB, Docker, Nginx, Gunicorn.
* **Logros:**
  * Desplegado: [https://projecto-formativo-steel.vercel.app/](https://projecto-formativo-steel.vercel.app/) (Frontend en Vercel, Backend en Render, BD en Neon PostgreSQL y MongoDB).
  * Visor 3D interactivo en Three.js para renderizado en tiempo real, incrementando retención de usuarios en un 25%.
  * 10 endpoints REST seguros integrados con pasarela Wompi, Cloudinary y OAuth2.
  * Cobertura de pruebas automatizadas del 85% (Jest, Pytest) y despliegue orquestado en Docker con CI/CD.

### [☕ Arquitectura de Microservicios con Spring Boot](https://github.com/josuel-munendez/Proyecto1_springsena)
Sistema backend desacoplado bajo principios de diseño limpio y aislamiento de dominios.
* **Stack:** Java 21, Spring Boot, JPA, JDBC, MySQL, H2, Maven.
* **Logros:**
  * Diseño de 3 microservicios independientes (usuarios, productos, vehículos) con aislamiento transaccional.
  * Implementación de 15 endpoints REST con patrón Controller-Service-Repository y consultas parametrizadas contra inyecciones SQL.

### [🎫 Sistema de Tickets de Soporte TI (Prueba Técnica)](https://github.com/josuel-munendez/tickets-soporte-ti)
Herramienta web corporativa para el registro, asignación y seguimiento de tickets de soporte para usuarios internos.
* **Stack:** PHP, MySQL, JavaScript, HTML5, CSS3, Bootstrap.
* **Logros:** Flujo completo de gestión de incidencias, roles de usuario y control de estados.

### [📊 Sistema de Gestión de Clientes (CRM)](https://github.com/josuel-munendez/ProyectoDJviernes)
Módulo backend desacoplado enfocado en alta mantenibilidad y seguridad multiperfil.
* **Stack:** Django, Python, PostgreSQL, MySQL, Docker, Bootstrap.
* **Logros:**
  * Implementación de patrones Repository y Service Layer, agilizando migraciones de base de datos de días a minutos.
  * Control de acceso basado en roles (RBAC) para seguridad en módulos administrativos contenerizados en Docker.

### [🎮 Star Collection — Estructuras de Datos desde Cero](https://github.com/josuel-munendez/star-collection)
