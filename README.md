<h2 align="center">🚀 PROYECTOS DESTACADOS</h2>

- 🛒 **RED Estampación (E-commerce con Editor 3D):** Plataforma full-stack desarrollada para cliente real. Integra visor 3D interactivo en React.js y Three.js, backend robusto en Django, pasarela de pago Wompi y despliegue automatizado con Docker, Nginx y CI/CD (85% de cobertura de pruebas).
